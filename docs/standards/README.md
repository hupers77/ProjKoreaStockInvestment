## 새 경제 프로그램을 시작할 때 순서

1. **요청 작성**: 01의 "새 프로젝트 시작" 템플릿을 채운다.
2. **기획**: 02의 기획서 1장, 판단 규칙서 v1, 데이터 소스 표를 만든다. 08 체크리스트로 빠진 항목을 확인한다.
3. **데이터 스파이크**: 실데이터 1일치를 실제 환경(내 PC)에서 받아 본다. 응답 표본을 저장한다.
4. **설계**: 03의 설계 문서 템플릿으로 구조·데이터 모델·상태별 동작을 정한다.
5. **화면 시안**: 04 기준으로 주요 화면 시안 2~3개를 보고 고른다.
6. **개발**: 05 기준으로 구현한다. 테스트를 같이 쓴다.
7. **검증**: 06의 출시 전 체크리스트와 백테스트 점검표를 통과한다.
8. **운영**: 07 기준으로 자동 실행, 알림, 백업을 설정한다.
9. **회고**: 끝나면 00 형식으로 회고를 남기고, 이 표준을 갱신한다.

## 이번 프로젝트에 바로 적용할 개선 목록 (회고에서 도출)

우선순위 순서다. 진행하려면 번호로 요청하면 된다.

1. 채점 엔진 단위 테스트 + 데모 스캔 통합 테스트 + GitHub Actions
2. 패키지 버전 상한·잠금 파일 (특히 pykrx, FinanceDataReader)
3. 외부 응답 검증과 실제 응답 녹화(fixture) 기능
4. KRX 비밀번호·DART 키를 키체인 또는 `.env`로 이동
5. 화면 하단 버전 표시, CHANGELOG
6. 투자검증: 여러 기준일 반복, 거래 비용 반영
7. 스캔 결과 알림 (보유 종목 경고, 신규 A 이상)
8. OS 스케줄러 등록 안내 (앱이 꺼져 있어도 스캔)
9. 지표 툴팁(정의·계산식·읽는 법)과 면책 문구
10. 휴장일·장 종료 시각을 설정으로 분리
