# 04. 화면(UI)·디자인 표준

> 이번 프로젝트에서 요청의 약 3분의 1이 화면·표시 수정이었다 (시장 환경 표시 3회 변경, 종가 선 색, 돌아가기 버튼, 검색 조건 유지 등).
> 이 표준을 먼저 정하면 대부분의 왕복을 없앨 수 있다.

---

## 1. 화면 설계 순서

1. **화면 목록과 이동 흐름**을 먼저 그린다 (대시보드 → 종목 상세 → 돌아가기).
2. 화면마다 "이 화면에서 사용자가 내리는 결정"을 한 줄로 쓴다.
   - 대시보드: 오늘 새로 볼 종목이 있는가
   - 종목 상세: 이 종목을 살까/계속 들고 있을까
   - 투자검증: 이 기준을 믿어도 되는가
3. 핵심 지표를 위에, 상세를 아래에 둔다.
4. 표시 방식이 여러 가지로 가능하면 **시안 2~3개**를 보여주고 고른다.

## 2. 한국 금융 화면 색 규칙

| 의미 | 색 | 비고 |
|---|---|---|
| 상승 / 이익 | **빨강** (#D60000 계열) | 한국 관례. 해외 관례(초록=상승)와 반대 |
| 하락 / 손실 | **파랑** (#0051C7 계열) | |
| 보합 | 검정/회색 | |
| 경고·위험 | 주황/빨강 배경 + 아이콘 | 상승 빨강과 헷갈리지 않게 **배경·아이콘**으로 구분 |
| 등급 (이번 구현) | S 진한 초록, A 연초록, B 노랑, C 회색, 제외 붉은색 | 등급색은 상승/하락색과 겹치지 않게 |

- **색만으로 의미를 전달하지 않는다.** +/− 부호, ▲▼ 기호, 글자(좋음/나쁨)를 함께 쓴다. 색약 사용자를 고려한다.
- 차트 주요 선(종가)은 보조 선(이동평균)보다 굵고 진하게. 검정 배경/흰 배경 모두에서 보이는 색. (이번: 검정 종가가 안 보여 녹색 2.5px로 변경)
- 다크 모드를 지원하면 모든 색을 변수(CSS 변수)로 정의한다.

## 3. 숫자 표시 규칙

| 대상 | 형식 | 예 |
|---|---|---|
| 가격 | 원, 천 단위 쉼표, 소수 없음 | 72,300 |
| 등락률 | 부호 + 소수 2자리 + % | +3.25%, −1.08% |
| 시가총액·거래대금 | 억/조 단위 | 4,520억, 1.2조 |
| 점수 | 정수 또는 소수 1자리 | 82.5 |
| 날짜 | YY/MM/DD (좁은 칸), YYYY-MM-DD (상세) | 26/10/02 |
| 소요 시간 | 사람이 읽는 형식 | 3분 12초 |
| 결측 | `–` 또는 `N/A` (0으로 표시 금지) | |
| 추정값 | 값 옆에 "추정" 표시 | 6 (추정) |

- 숫자 열은 **오른쪽 정렬**, 글자 열은 왼쪽 정렬.
- 같은 열 안에서 단위를 섞지 않는다.

## 4. 표(순위표) 규칙

- 정렬·필터·검색 조건은 **다른 화면에 다녀와도 유지**한다 (이번 요청 반영됨). "조건 초기화" 버튼을 둔다.
- 요약 칸(등급별 종목 수)을 누르면 표가 그 조건으로 필터된다.
- 페이지 단위(20/50/100)를 정하고 총 건수를 보여준다.
- 첫 열 고정(종목명), 머리글 고정.
- 표에 보이는 조건 그대로 내려받기 (CSV는 한글 깨짐 방지 BOM, XLSX는 머리글 고정·필터).
- 행 왼쪽의 상태 표시(보유 여부 라디오 등)는 누르면 바로 저장되고, 결과를 짧게 알린다.

## 5. 차트 규칙

- 축 이름과 단위를 쓴다. 이중 축은 오른쪽 축 단위를 명확히 (이번: 거래대금 억 원 우측 축).
- 기준일·이벤트는 **세로 점선**과 이름표로 표시.
- 과거/미래 구간을 나눌 때는 실선/점선 또는 진하기로 구분.
- 하루에 여러 값이 있으면 집계 규칙(마지막 값)을 정하고 툴팁에 밝힌다.
- 시계열은 거래일만 표시해서 주말 공백을 없앤다.
- 차트 라이브러리는 로컬 파일로 포함해 오프라인에서도 동작하게 한다 (이번: `chart.umd.min.js`).

## 6. 상태 표시 (빈 화면 금지)

모든 화면에 아래 상태를 설계한다.

| 상태 | 표시 예 |
|---|---|
| 첫 실행 (데이터 없음) | "아직 스캔한 기록이 없습니다. [지금 스캔]을 눌러 주세요 (첫 스캔 10~30분)" |
| 진행 중 | 진행률, 현재 단계, 경과 시간 |
| 부분 실패 | 성공한 부분 표시 + 노란 경고 목록 |
| 실패 | 어느 단계에서 왜 실패했는지 + 사용자가 할 일 |
| 데이터 아직 없음 | "기준일 이후 거래일 시세가 아직 없어 수익률을 계산할 수 없습니다" |
| 버튼 사용 불가 | 비활성 대신, 누르면 이유와 해결 방법 안내 (이번 재계산 버튼 사례) |

## 7. 도움말·설명

- 모든 지표 이름에 마우스를 올리면 **정의, 계산식, 읽는 법**을 보여준다 (시장 환경 점수, 커버리지 같은 질문이 화면 안에서 해결되도록).
- 설정값 옆에 "이 값을 바꾸면 생기는 일"을 한 줄로 쓴다 (예: "낮추면 A·S 등급이 늘어납니다").
- 아이콘·이모지로 상태를 보여줄 때는 툴팁 글자를 같이 둔다 (🌞 좋음 / 🌤️ 보통 / ☁️ 주의 / 🌧️ 나쁨).
- 화면 하단에 **면책 문구**: "이 프로그램은 정보 제공용이며 투자 권유가 아닙니다. 투자 판단과 책임은 사용자에게 있습니다."
- [보강] 화면 하단에 프로그램 버전·마지막 업데이트 표시.

## 8. 이동·조작

- 상세 화면에는 항상 "돌아가기"가 있고, 이전 화면의 조건을 그대로 복원한다. 직접 연 경우 대시보드로.
- 위험한 버튼(삭제, 1년 기록 삭제)은 확인 창을 띄우고, 무엇이 지워지는지 구체적으로 쓴다.
- 자주 쓰는 동작(재계산, 지금 스캔)은 주요 색 버튼, 드문 동작은 보조 버튼.
- 휴대폰 화면: 표는 가로 스크롤, 핵심 열(종목·등급·점수·등락)만 기본 표시. [보강] 이번에는 모바일 스타일이 거의 없었다.

## 9. 접근성·품질 기준

- 글자 대비 4.5:1 이상
- 클릭 영역 최소 32×32px (모바일 44px)
- 키보드로 주요 동작 가능 (Enter로 저장)
- 파비콘·탭 제목에 화면 이름

## 10. 시안 요청·검토 체크리스트

- [ ] 이 화면에서 내리는 결정이 한 줄로 정의되었는가
- [ ] 상승/하락 색이 한국 관례인가, 색 외의 표시가 있는가
- [ ] 숫자 단위·정렬이 표준과 맞는가
- [ ] 6장의 상태가 모두 설계되었는가
- [ ] 지표마다 설명이 있는가
- [ ] 휴대폰에서 어떻게 보이는가
- [ ] 면책 문구와 버전 표시가 있는가
