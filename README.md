# 종목 선정 대시보드

평가 기준서(`korean-stock-scoring-framework.md` v1.0)대로 KOSPI·KOSDAQ 전 종목을 매일 채점하고, 브라우저에서 보는 웹 프로그램입니다. Windows, macOS, Linux 어디서나 같은 방식으로 실행됩니다.

## 1. 설치·실행

1. Python 3.10 이상을 설치합니다 (Windows는 설치 화면에서 "Add python.exe to PATH"를 체크하세요).
2. 이 폴더를 내 컴퓨터에 둡니다.
3. 실행합니다.
   - Windows: `run.bat` 더블클릭
   - macOS/Linux: 터미널에서 `./run.sh`
4. 브라우저가 열립니다: http://127.0.0.1:5000 . 처음 한 번은 패키지 설치 때문에 몇 분 걸립니다.

휴대폰에서 보려면 `run.bat --host 0.0.0.0` 로 실행한 뒤, 같은 와이파이에서 `http://<PC의 IP>:5000` 으로 접속하세요.
Docker를 쓰면: `docker build -t stockapp . && docker run -p 5000:5000 -v $(pwd)/data:/app/data stockapp`

## 2. 무료 데이터 연결 (설정 메뉴)

| 데이터 | 가입처 | 쓰이는 항목 |
|---|---|---|
| 시세·거래대금·외국인/기관 수급·PER/PBR/배당 | 한국거래소 [data.krx.co.kr](https://data.krx.co.kr) 무료 회원 (아이디/비밀번호 입력) | 단기 대부분, M07·M09·M13~M15, L10·L16·L20 |
| 분기·연간 재무제표 | 금융감독원 [OpenDART](https://opendart.fss.or.kr) 무료 인증키 | S14, M01~M04, L01·L03~L05·L08·L11·L15, K3·K10 |
| 관리종목 목록·환율 | 가입 필요 없음 (FinanceDataReader) | K1, S18 |

- 첫 스캔은 약 1년치 일별 시세와 5년치 재무를 받아 저장하므로 오래 걸립니다(대략 10~30분). 다음 날부터는 하루치만 받습니다.
- 데이터는 `data/stock.db` 한 파일에 저장됩니다. 백업할 때 이 파일만 복사하면 됩니다.

## 3. 화면

- **대시보드**: 등급별 종목 수, 시장 환경, 보유 종목 점검(등급 하락·손절가 이탈·점수 급락 경고), 전체 순위표(검색·등급·시장·업종 필터, 정렬). 순위표는 현재 검색 조건·정렬 그대로 CSV·Excel(xlsx)·Markdown 파일로 내려받을 수 있습니다.
  - 종목명 배경색 = 등급: S 진한 초록(90+), A 연초록(80~89), B 노랑(70~79), C 회색(70 미만), 제외 필터 해당 = 붉은색 취소선.
  - 종목명 왼쪽 라디오 버튼 = 보유 여부. 누를 때마다 보유 등록/해제됩니다.
- **종목 상세**: 관점별 점수·커버리지, 62개 항목의 데이터값·점수·근거, 목표가·손절가, 주가 차트, 점수 추이. 자동으로 못 구하는 항목(해자, 지배구조, 컨센서스 등)은 0~10점을 직접 입력하면 즉시 재계산되고 이후 스캔에도 계속 적용됩니다. 가점·감점(B1~B4, D1~D7)도 체크로 입력합니다.
- **보유·제외 종목**: 매수가·수량·매수일·메모 등록, 제외 종목 등록(다음 스캔부터 순위에서 빠짐).
- **스캔 기록**: 실행 이력, 경고, 지금 스캔 / 데모 스캔 버튼.
- **평가 기준**: 항목별 자동/수동 구분, 기준서 권장 가중치와 프로파일별로 수정할 수 있는 가중치.
- **설정**: 자동 스캔 시각(평일, 기본 18:30), 적용할 투자 성향 프로파일(초단기 90·10·0, A~D, 기본 C 균형형), 프로파일별 K7·K8 기준과 등급 게이트 커버리지, 데이터 계정. 스캔에는 적용 중인 프로파일의 기준과 가중치가 쓰입니다.

자동 스캔은 프로그램이 켜져 있을 때 실행됩니다. 컴퓨터를 켜 둘 수 없다면 Windows 작업 스케줄러나 cron으로 `python run.py --scan` 을 평일 저녁에 실행하게 할 수도 있습니다.

## 4. 기준서와 다르게 처리한 부분 (무료 데이터 한계)

- 무료로 구할 수 없는 항목(컨센서스, 신용잔고, 공시 촉매, 해자, 지배구조, 업황 등)은 N/A로 두고 분모에서 뺍니다(기준서 2-2). 수동 입력하면 반영됩니다.
- 대체 지표로 계산한 항목은 "추정" 표시와 함께 최대 6점입니다(기준서 10장): 후행 PER/ROE(M07·M09), 분기 연율화 이익(M04), 순이익 CAGR(L04), 부채비율만으로 본 재무구조(L08), 배당만 반영한 주주환원율(L11), RIM 단일 방법 안전마진(L15).
- S11(공매도·대차잔고)은 조사하지 않고 N/A로 둡니다(사용자 결정). S18은 VKOSPI 없이 나머지 3개 조건 비율로 채점합니다.
- S14는 기준서의 "컨센서스가 없으면 영업이익 YoY로 대체" 규칙을 씁니다.
- 커버리지는 관점별 커버리지를 프로파일 비중으로 가중 평균합니다. 자동 항목만으로는 보통 50~65% 수준이라, 기준서의 게이트(A 70%, S 80%) 때문에 A·S 등급이 나오지 않을 수 있습니다. 관심 종목의 핵심(★) 수동 항목을 채우면 커버리지가 올라갑니다.
- D4(6개월 300% 급등)는 테마 여부와 무관하게 가격 기준으로 자동 판정합니다.

## 5. 폴더 구조

```
run.py               실행 진입점 (--scan, --host, --port)
stockapp/framework.py  항목·가중치·프로파일·등급 정의
stockapp/scoring.py    채점 규칙 (항목별 함수, 제외 필터, 게이트)
stockapp/collector.py  KRX 시세·수급 수집 (pykrx)
stockapp/dart.py       OpenDART 재무 수집
stockapp/scanner.py    스캔 실행·저장
stockapp/web.py        웹 화면·API·자동 스캔 스케줄러
stockapp/demo.py       화면 확인용 가상 데이터
```

이 프로그램의 점수는 의사결정 보조 자료이며 손실이 없음을 보장하지 않습니다. 최종 투자 판단과 책임은 사용자에게 있습니다.
